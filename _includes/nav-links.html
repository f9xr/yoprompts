{%- comment -%} Emits one list item per primary navigation entry so the desktop bar and the mobile drawer can never drift apart. Callers supply the wrapping element. include.variant: "menu" (default) entries that declare `children` render as a hoverable / keyboard-reachable dropdown, with the parent page kept as the first row of the panel so the hierarchy still links both ways. "flat" children are emitted as their own list items underneath the parent. The mobile drawer has no room for a panel, so it gets the whole tree as one indented column instead. {%- endcomment -%} {%- assign variant = include.variant | default: 'menu' -%} {%- for item in site.data.nav.primary -%} {%- if item.children and variant == 'flat' -%}
  • {{ item.label }}
    • {%- for child in item.children -%}
  • {{ child.label }}
    • {%- endfor -%} {%- elsif item.children -%}
  • {{ item.label }}
    All {{ item.label }} {%- for child in item.children -%} {{ child.label }} {%- endfor -%}
    • {%- else -%}
  • {{ item.label }}
    • {%- endif -%} {%- endfor -%}
