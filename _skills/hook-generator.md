Hook Generator returns six openers for a topic, each built as a short first line followed by a contrasting second line. It favors concrete numbers and lived experience over generic curiosity gaps.

The skill asks for the topic and any real results, failures, or observations that can support the hook. If those are missing, it says the hook is a template and should not be published as a personal claim.

Output is intentionally fast and has no preamble. Each variation is different in angle, not just wording, so the writer can pick one and continue into a full post.
