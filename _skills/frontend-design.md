Frontend Design focuses on the decisions that make an interface feel specific: subject matter, hierarchy, type, spacing, color, and motion. It pushes back on generic dashboard and landing-page patterns.

The skill starts with a short design direction tied to the product, then builds against it and critiques the result. It covers type scale, layout rhythm, component states, and responsive behavior.

It is a design partner for implementation, not a component library. The output is guidance and concrete CSS decisions that can be handed to a coding agent.
