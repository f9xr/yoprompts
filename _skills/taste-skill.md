Taste Skill is built to stop landing pages from looking like the average of every page a model has seen. A script deals three directions from a library distilled from 247 real sites, and the agent picks the one that carries the subject's own idea.

The workflow is audit first on redesigns: record the current page, inventory what belongs to the subject, write the argument as claims with proof, then build from the dealt direction. Imagery comes from the project, generated assets, or credited open collections rather than placeholders.

A browser inspector measures the result at desktop, tablet, and phone widths, checking headline line counts, typography, margins, contrast, empty stretches, and motion. The build is not finished until those checks pass and the screenshots have been reviewed.
