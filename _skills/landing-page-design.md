Most landing pages fail before the first line of CSS because they serve several intents at once. This skill starts with one offer, one audience, and one primary action, then builds the argument in a deliberate order.

Part A covers intake, page structure, layout choice, conversion rules, copy formulas, build order, and the SEO decision. Part B is the visual system: one typeface, a fixed type scale, named text styles, a restricted spacing scale, radius rules, flat backgrounds, icon families, and motion that decelerates instead of using browser defaults.

It also enforces the details that make a page feel finished: full interactive states, honest sample content, no invented facts, legal links, a custom 404, form validation, alt text, and a 390px check with no horizontal overflow.

The skill is from the Elaya Design collection and adapts parts of Taste Skill, MIT licensed. Install it with the Skills CLI or copy the SKILL.md into your agent's rules file.
