--- layout: default --- {%- comment -%} Prompt hub: one crawlable landing page per category or per AI tool. Front matter: hub_kind: category | tool hub_slug: the value to match (`category` field, or membership of `tools`) Skills have had per-category hubs since launch; prompts only had /prompts/?category=… query URLs, which canonicalise back to /prompts/ and so can never rank for a job-level query. This layout gives each category and tool a real URL with its own title, description, count and ItemList. {%- endcomment -%} {%- assign kind = page.hub_kind -%} {%- assign hub_slug = page.hub_slug -%} {%- assign hub_items = "" | split: "" -%} {%- if kind == "category" -%} {%- assign hub_meta = site.data.categories | where: "slug", hub_slug | first -%} {%- for p in site.prompts -%} {%- if p.category == hub_slug -%}{%- assign hub_items = hub_items | push: p -%}{%- endif -%} {%- endfor -%} {%- else -%} {%- assign hub_meta = site.data.ai_tools | where: "slug", hub_slug | first -%} {%- for p in site.prompts -%} {%- if p.tools contains hub_slug -%}{%- assign hub_items = hub_items | push: p -%}{%- endif -%} {%- endfor -%} {%- endif -%} {%- assign hub_items = hub_items | sort: "title" -%} {%- assign hub_count = hub_items | size -%}
