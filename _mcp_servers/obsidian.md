The Obsidian server talks to the local REST API plugin and exposes vault operations: search notes, read a note, create one, and append to an existing file.

Use it when an agent needs to work with a personal knowledge base rather than a project folder. The REST API plugin must be installed and running, and the API key is generated by the plugin.

Keep the vault on the local machine and bind the API to localhost. The server has the same access as the plugin, so a shared or public bind exposes the whole vault.
