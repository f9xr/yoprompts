Content Matrix combines the writer's pillars with eight repeatable formats to produce a month of post ideas. Each cell names the format, the angle, and a working title rather than a vague topic.

It reads `about-me.md` and `voice.md` when they exist, so ideas stay inside the writer's actual expertise. Without those files it asks for pillars and context first.

The result is a planning table, not a set of drafts. The writer can hand any row to post-writer or hook-generator for the next step.
